نسخة V2 من صفحة أصيلة ASEELA.

- `index.html`
- `assets/product.png`

## قبل الإطلاق التجاري
عدّل داخل `index.html`:
1. رقم واتساب داخل JavaScript.
2. رابط فيسبوك.
3. السعر وأحجام العبوات.
4. بيانات المكونات والقيمة الغذائية.
5. تاريخ الإنتاج والصلاحية ورقم التشغيلة.
6. بيانات المنتج/الشركة المطلوبة قانونيًا.
7. صور المنتج النهائية بدل الصور التجريبية عند اعتماد العبوة.

## GitHub Pages
